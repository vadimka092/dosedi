# Сервис доставки еды (Food Delivery Service)

Веб-приложение для автоматизации приема заказов, управления меню и отслеживания статуса доставки. 
В рамках Лабораторной работы №2 реализованы три ключевые функции: создание заказа, просмотр списка и обработка ошибок.

## Реализованные функции

1. **Создать заказ** (`/orders/new` + `POST /orders`) — данные проверяются и сохраняются в JSON-файл.
2. **Посмотреть заказы** (`/orders`) — отображается таблица со всеми оформленными заказами.
3. **Ошибочный сценарий** — при пустом названии блюда выводится страница отказа (`/error`), запись не создается.
