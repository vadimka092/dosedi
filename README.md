# Сервис доставки еды

Система для автоматизации приема заказов, управления меню ресторанов и отслеживания статуса доставки курьерами. Первая страница проекта отображает название сервиса, его назначение и статус разработки.

## Версии для запуска

Работа | Тег образа | Что открывается  
---|---|---  
ЛР1 | `0.0.1` | Первая страница: название, описание, версия и статус разработки  

Опубликованный тег **0.0.1** содержит **linux/amd64 и linux/arm64**. Docker выбирает архитектуру автоматически. На Windows/macOS нужен Docker Desktop в режиме Linux-контейнеров, на Linux — Docker Engine. Node.js и зависимости находятся внутри образа.

## Запуск ЛР1

**1\. Скачайте образ.**

    docker pull ваш_логин/fooddelivery-app:0.0.1

**2\. Запустите контейнер.** Порт 8080 должен быть свободен.

    docker run --rm -p 8080:8080 ваш_логин/fooddelivery-app:0.0.1

**3\. Откройте http://localhost:8080.** На странице видны название системы, описание, версия **0.0.1** и статус разработки. Остановка — **Ctrl+C**.

## Если порт занят

Используйте другой порт компьютера, например 8081:

    docker run --rm -p 8081:8080 ваш_логин/fooddelivery-app:0.0.1

Откройте http://localhost:8081.
